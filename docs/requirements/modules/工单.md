# 工单

## 概述

工单（咨询 / Bug / 需求）的提交、补充、后台确认转出，以及与 Gitea Issue 的双向同步。

---

## 核心功能

> 按需求状态标记：已完成 | 开发中 | 规划中

| 功能 | 需求编号 | 状态 | 说明 |
|------|----------|------|------|
| 需求多视角分层补充 | REQ-001 | 已完成 | 使用者 / 业务方 / 专家 / 决策者分视角补充需求，Issue 分层呈现 |
| 转研发后驳回与迁移就绪检查 | REQ-002 | 已完成 | 已转研发工单驳回并关闭关联 Issue（可重试）；只读迁移状态检查 |

---

## 业务规则

| 规则 | 说明 |
|------|------|
| 视角与权限独立 | 视角（Perspective）只用于需求内容归类，不授予权限；权限仍由固定角色决定 |
| 驳回为本地终态 | 转研发后驳回的工单不再被 Gitea 回流改变状态；只关闭关联的主 Issue |
| 视角标签固定 | `<前缀>/视角/<视角名>`（默认前缀 `lingo`，如 `lingo/视角/业务方`）；视角名不可修改 |
