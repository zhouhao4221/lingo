# 知识问答

## 概述

知识问答 Agent：用户用自然语言提问，灵工基于工单、版本记录与知识库作答；答不了时引导转为工单。

---

## 核心功能

> 按需求状态标记：已完成 | 开发中 | 规划中

| 功能 | 需求编号 | 状态 | 说明 |
|------|----------|------|------|
| 工单与版本问答 | REQ-003 | 已完成 | 用自然语言查询工单进展与近期发版 |
| 知识库一期：答复入库与检索作答 | REQ-006 | 已完成 | 后台答复时勾选入库、手动维护，提问时检索作答 |
| 知识库二期：抽取、反馈与审核 | REQ-007 | 已完成 | 结案工单抽取、回答反馈入库（待审核）、未答上统计 |
| 业务数据 Tool（只读） | REQ-008 | 开发中 | 问答与 MCP 以用户权限调用接入方注册的只读工具 |
