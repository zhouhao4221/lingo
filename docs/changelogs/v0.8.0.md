# v0.8.0（2026-11-25）

知识库二期：知识库可以自动增长——结案工单由模型抽取问答、用户认可的回答进入候选，两者经 reviewer 审核后生效；后台对外评论也可勾选入库；统计知识类问题没答上的提问。公开 API 只增不改；新增迁移 `0006_knowledge_review.sql`，升级后需执行 `lingo.Migrate`。

要求：Go 1.24+、PostgreSQL 13+、Gitea 1.22+（同 v0.7.0）。不需要数据库扩展。

## 新功能 (Features)

- **知识库二期**（#46、#47，REQ-007）
  - **结案工单抽取**：Bug / 需求工单首次进入已发布、已上线或已关闭（未修复）后，`Run` 用轻量模型（未配置时为 `Model`）抽取一条"现象 → 原因 / 解决办法 / 修复版本"问答，**待审核**；每张工单最多抽取一次（多实例下有唯一约束兜底），失败最多重试 3 次；未配置模型时不抽取。**升级到本版本时已结案的工单不抽取**（迁移时登记为已跳过）。
  - **回答反馈**：`RateMessage(ctx, u, convID, msgID, helpful)`、REST `POST /conversations/{id}/messages/{mid}/feedback`（`{"helpful":bool}`）、MCP `rate_message`。以最后一次为准，回答引用的知识条目累加有帮助 / 没帮助次数（并发与改选都只按差值计）；知识类问题的回答第一次被标为有帮助时，提问与回答（去掉工单号与知识编号、脱敏）作为**待审核**候选入库，一条回答最多一个候选。
  - **评论入库**：`AddTicketCommentWith(ctx, u, id, CommentInput{Body, Attachments, Knowledge})`（REST `POST /tickets/{id}/comments` 带 `knowledge`，MCP `reply_ticket` 带 `add_to_knowledge`）：reviewer / admin 发表对外评论时可加入知识库，直接生效，与评论同一事务。`AddTicketComment` 不变。
  - **审核**：`ListKnowledge`（`Status: KnowledgePending`）列出待审核条目；`ApproveKnowledge`（可带编辑后的内容）/ `RejectKnowledge`，REST `POST /knowledge/{id}/approve|reject`；不是待审核时返回 `ErrConflict`。入库时与已生效条目重合比例不低于 60% 的标出 `duplicate_of`（只提示）。待审核与已驳回的条目不参与检索与回答。`DisableKnowledgeByTicket` 同时驳回该工单的待审核候选。
  - **未答上的问题**：知识类问题没有命中时，在提问人可访问的项目里各记录一条脱敏后的提问，近 90 天同项目的同类提问归并计数；`ListUnansweredQuestions`、REST `GET /knowledge/unanswered` 按次数列出（reviewer / admin），过期记录由 `Run` 清理。
  - `KnowledgeEntry` 新增 `duplicate_of`、`helpful_count`、`unhelpful_count`（维护接口返回）。用量新增 `knowledge_extract`。

## 行为变化

- **检索相关度**：知识库检索只返回重合词数不少于"提问与条目中词数较少一方"20% 的条目。v0.7.0 中只因"怎么""为什么"等常用词重合的无关条目不再命中，相关条目不受影响（长问题也能找到短条目）。
- **停用 / 恢复幂等**：对已是目标状态的条目调用 `DisableKnowledge` / `EnableKnowledge` 直接返回成功。

## 数据库

- **新增迁移 `migrations/0006_knowledge_review.sql`**：`lingo_knowledge` 放宽状态（新增 `pending` / `rejected`）与来源（`ticket_extract` / `assistant_feedback` / `ticket_comment`）约束，新增来源消息、可能重复、有帮助 / 没帮助次数等列；新增 `lingo_assistant_feedback`、`lingo_knowledge_extractions`、`lingo_knowledge_misses` 三张表。0001–0005 未改动。
- **升级需执行迁移**：在发布流程中调用 `lingo.Migrate(ctx, db)`，可先用 `lingo.CheckMigrations` 确认就绪。0006 随本版本发布，之后不再修改。

## 升级

```sh
go get github.com/zhouhao4221/lingo@v0.8.0
```

- 升级后执行 `lingo.Migrate(ctx, db)`，应用 0006。
- 想让知识库从结案工单自动增长，配置 `LightModel`（或 `Model`），并安排 reviewer 处理待审核条目（`GET /knowledge?status=pending`）；不审核的候选不会影响回答。
- 在问答界面为回答加上"有帮助 / 没帮助"按钮，调用 `RateMessage`。
