# v0.4.0（2026-11-24）

新增知识问答首期：用户在对话里用自然语言询问工单进展、修复版本、上线情况和近期发版，灵工按调用者的权限查询后作答，回答附上引用的工单与版本；在对话中给工单留言须经用户确认。会话只有本人可见，支持流式输出。公开 API 只增不改；新增迁移 `0003_assistant.sql`，升级后需执行 `lingo.Migrate`。

要求：Go 1.24+、PostgreSQL 13+、Gitea 1.22+（同 v0.3.0）。

## 新功能 (Features)

- **知识问答：工单与版本问答**（#33，REQ-003）
  - **会话**：`CreateConversation` / `ListConversations` / `ListConversationMessages` / `DeleteConversation`。会话只有创建者本人可见，admin 也看不到他人的会话；删除为软删除，灵工不自动清理。
  - **提问**：`SendMessage` / `SendMessageStream`（`onDelta` 逐片段回调），`RetryMessage` / `RetryMessageStream` 重试最近一次提问的失败回答。`MessageInput.TimeZone` 用于理解「今天」「上周」，缺省为服务进程的本地时区。
  - **能回答的问题**：工单进展、修复版本与上线情况（按时间、类型、状态、项目、仓库、关键词查找，多张命中时列出候选）；工单数量与列表汇总；近期发版、版本说明摘要与修复的工单。其他问题如实说明「只能回答工单和版本相关问题」，并提示可以提交咨询工单。
  - **权限**：可见范围与 `GetTicket` 相同（external 只看本人的，agent 只看已转出的，reviewer / admin 看 `User.Projects` 内全部），汇总与版本修复的工单同样受控；无权访问与不存在的回答一致。
  - **对话中留言须确认**：要求留言时，助手消息带 `PendingAction`；用户点确认（`ConfirmPendingAction`）或在下一条消息中回复确认后才写入，写入行为与 `AddTicketComment` 相同（同步到 Issue、通知提交人）。30 分钟内有效，取消、发送无关消息或超时后作废；确认时被拒（无权限、工单状态不允许）记为 `failed` 并说明原因。回答进行中，确认 / 取消按钮返回 `ErrConflict`。
  - **防编造与防注入**：模型只把提问解析为查询意图，查询由灵工按调用者身份执行；回答出现数据之外的工单号时改用按数据生成的回答。工单正文、评论、版本说明中的指令不会触发写操作；留言正文须是用户原话。
  - **送给模型的内容**：提问与最近 10 轮对话；工单的编号、项目、仓库、类型、标题、状态、时间、修复版本、里程碑与正文摘要；回答单张工单时附最近 5 条评论（按提问人可见范围）；版本名称、说明摘要、上线记录与修复的工单。不含提交人与评论作者的姓名、邮箱、用户 ID，也不含表单字段、提交环境与附件。
  - **模型**：意图解析与确认判断用 `LightModel`（为空时用 `Model`），组织回答用 `Model`。未配置 `Model` 时发送与重试返回新增的 `ErrNoModel`（REST 501 `model_not_configured`），会话列表、历史、确认与取消照常可用。模型用量记入 `LLMUsage`，新增用途 `assistant_intent`、`assistant_confirm`、`assistant_answer`。
  - **流式**：新增可选接口 `lingo.StreamModel`，内置的 `NewOpenAIModel` / `NewDeepSeekModel` 已实现；未实现时整段生成后推送一次。流式回答未收到结束标记就断开时记为失败；兼容接口忽略 `stream` 或拒收 `stream_options` 时自动降级。
  - **REST**：`POST` / `GET /conversations`、`DELETE /conversations/{id}`、`GET` / `POST /conversations/{id}/messages`（`stream: true` 时以 SSE 返回若干 `delta` 和恰好一个 `message` 事件）、`POST /conversations/{id}/messages/{mid}/retry`、`POST /conversations/{id}/actions/{aid}/confirm|cancel`。
  - **MCP**：新增 `ask`、`list_conversations`、`list_conversation_messages`、`confirm_action`、`cancel_action`（整段返回）。

## 升级

```sh
go get github.com/zhouhao4221/lingo@v0.4.0
```

- 升级后执行 `lingo.Migrate(ctx, db)`，应用 0003。
- 不调用新增方法、不挂载新路由时，现有行为不变。要启用知识问答，配置 `Config.Model`（可另配便宜的 `LightModel`）。
- 流式回答受 `OpenAIConfig.HTTPClient` 超时限制（默认 90 秒，是整段回答的时限）。
